DENTALHEALTH · DEVELOPER ACCESS

Dental care, connected.

The DentalHealth API manages patient, student and doctor accounts, profiles and patient-submitted dental cases.

This deployment provides a JSON API and Django administration. It does not include a patient-facing website or mobile application.

ActionMethodEndpoint
RegisterPOST/api/register/
Sign inPOST/api/login/
Refresh tokenPOST/api/token/refresh/
View or update profileGET, PUT, PATCH/api/profile/
Create a casePOST/api/cases/create/
List casesGET/api/cases/
Update case statusPATCH/api/cases/{id}/status/
Sign outPOST/api/logout/
Delete own accountDELETE/api/account/delete/

Authenticated requests use Authorization: Bearer <access token>. Uploaded images also require authentication. Doctors need administrator approval before accessing clinical cases.
